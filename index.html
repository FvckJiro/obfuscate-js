Get key

Free access takes three steps. Finish the checkpoint, copy your key, and it works until it expires. Then repeat the checkpoint.

  1. Complete the checkpoint

    Open each link, wait for the timer to finish, then press Continue.

    Loading...

  2. Copy your key

    Your key shows up here after the last checkpoint. Copy it exactly, with no spaces.

  3. Run the script

    Paste the key into the key box when the script opens. Don't have a loader yet? Copy one from the Scripts tab.

    script_key = "YOUR-KEY"
